📖 티카투카 : 운명의 주사위 규칙

1. 50:50 코인 토스 & 18칸 완주 2선승제

매 판 시작 시 코인 토스(50:50)로 선공을 정합니다. 한쪽 9칸이 먼저 차면 해당 턴은 자동 패스되며, 양쪽 18칸(나 9칸 + 상대 9칸)이 전부 채워져야 종료됩니다. 3개 열 중 2개 이상 점수가 높으면 승리하며, 열 승수와 총점까지 모두 동점인 무승부 시 나 승리 판정으로 처리됩니다.

2. 같은 눈 보너스 (+1개 / +2개 추가 합산)

같은 열에 동일한 눈 주사위가 모이면 보너스 개수가 추가 합산됩니다:
• 2개 모임 (+1개 보너스): 동일 눈 1개 추가 → 예: 2, 2면 2+2+2 = 6점 (4, 4면 12점)
• 3개 모임 (+2개 보너스): 동일 눈 2개 추가 → 예: 2, 2, 2면 2×5 = 10점 (4, 4, 4면 20점)

3. 알까기 (직접 발사 & 연결된 동일 눈 일괄 파괴)

• 내 열에 빈 칸이 1칸 이상 있고 맞은편 상대 열에 같은 눈(고정 주사위 제외)이 있으면, 내 열이나 상대 열을 클릭해 주사위를 직접 발사하여 파괴합니다.
• 맞은편에 같은 눈이 2~3개 연결되어 있으면 한꺼번에 전부 날아가며, 알까기한 내 주사위도 함께 소멸합니다.

4. 고정 주사위 & 리롤 (타짜의 손놀림)

• 선공 첫 주사위: 코인 토스 승자의 첫 주사위는 고정 주사위이며, 자신의 진영 빈 칸에만 배치 가능하고 정규 턴이므로 리롤(1회) 가능합니다.
• 알까기 보너스 고정 주사위: 알까기 성공 시 얻는 고정 주사위는 내 빈 칸 또는 상대 빈 칸(방해 투척) 모두 배치 가능하며, 보너스 턴이므로 리롤할 수 없습니다.
• 타짜의 손놀림(리롤): 게임당 1회 사용 가능하며, 리롤 시 기존과 같은 눈은 나오지 않고 다른 눈이 나옵니다.
